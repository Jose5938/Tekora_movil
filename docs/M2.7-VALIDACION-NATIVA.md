# M2.7 · Pulido y validación nativa

Se apila sobre M2.6. Inicio conserva su diseño y ofrece acceso directo a solicitudes y reservas. La navegación inferior anuncia la pestaña activa. Seguimiento, reservas, conversaciones y notificaciones mantienen un ancho legible en pantallas amplias y sus controles funcionan a 320 px. El formulario de solicitud permite pulsar enviar con el teclado visible.

Las lecturas con 429 o 503 respetan `Retry-After` cuando el servidor lo aporta. Admite segundos y fecha HTTP. Los controles de refresco no reenvían esa consulta durante la espera y el reintento posterior requiere acción manual. El flujo de sesión de 10A se conserva: volver a primer plano revalida con `/me` antes de mostrar datos privados, y reiniciar requiere login. Los cambios de versión siguen resolviéndose consultando el estado actual del servidor.

## Matriz para el dispositivo físico

La exportación verifica que Metro produce bundles Android e iOS. Quedan pendientes instalar un cliente SDK 58, validar los módulos nativos y conectar una API Laravel aprobada. En este entorno no hay dispositivo Android ni herramientas iOS. No se construyeron distribuciones firmadas.

Usar un cliente Expo compatible con SDK 58 y un Laravel de pruebas separado, con HTTPS de confianza para el dispositivo. La URL pública de la API termina en `/api/v1`. El laboratorio local B3.2, las cuentas reales y las bases comerciales quedan fuera de esta prueba.

| Control | Resultado a comprobar |
| --- | --- |
| Login y reinicio | Inicio tras login. Reapertura de proceso exige autenticación. Sin uso del token anterior ante fallo de borrado. |

Repetir en Windows la instalación, ambos Node, generación de tipos Expo, TypeScript y lint. El SDK conserva Expo 58.0.26. La única dependencia nueva de esta pila es Expo Crypto, seleccionada por la matriz SDK 58 en M2.3.

No se necesitan rutas nuevas para los incrementos entregados. Las acciones de prestador, registro, recuperación de contraseña, reseñas de escritura y pagos móviles siguen fuera del contrato consumido. No se modificó Laravel ni se abrió un servidor público.
